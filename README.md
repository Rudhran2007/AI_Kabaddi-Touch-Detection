Overview

The AI-Based Kabaddi Touch Detection System is a computer vision project that automatically detects touch events between the raider and defenders from Kabaddi match videos. The system uses YOLOv8 Pose, OpenCV, and ByteTrack to detect players, track their movements, and identify touched defenders.

Features:
Detects players in Kabaddi match videos.
Tracks players using unique IDs.
Identifies the raider's hand position.
Detects defenders touched by the raider.
Displays:
Player IDs
Touched player count
IDs of touched defenders
Provides real-time visualization with bounding boxes.

Technologies Used:
Python
OpenCV
YOLOv8 Pose (Ultralytics)
PyTorch
ByteTrack
NumPy
